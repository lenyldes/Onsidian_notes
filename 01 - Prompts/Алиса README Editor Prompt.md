# 📄 README Editor — Очеловечивание и редактура README

Промт для рерайтинга и технической редактуры машинно-сгенерированной или переведённой документации (`README.md`). Помогает превратить неестественный «переводной» язык в живую, грамотную и профессиональную русскую документацию от разработчика с полным сохранением Markdown-структуры, схем, таблиц и терминов.

````text
У меня есть текст README.md (целиком или только его часть) для IT‑проекта — он сгенерирован англоязычной нейросетью, поэтому звучит неестественно, местами перегружен и будто «переводной».

Твоя задача: перефразировать текст так, чтобы он звучал как будто его писал русскоязычный разработчик — живым, профессиональным, но без лишнего пафоса. Исправь пунктуацию, подправь формулировки, убери канцелярит и неестественные обороты.

При этом:

Не меняй структуру: сохрани все заголовки, списки, таблицы, блоки кода, диаграммы и порядок разделов.
Не меняй разметку. Например не заменяй ||| на '''
Не добавляй новую информацию и не сокращай смысл: если в оригинале есть детали (цифры, версии, лимиты, пути), оставь их.
Сохрани форматирование: Markdown‑разметка должна остаться валидной. Таблицы, списки, блоки кода и диаграммы — без изменений в компоновке.
Термины и стек оставь на английском, если это общепринятые названия (Go, PostgreSQL, Docker, CI/CD, TDD и т. п.).
Ссылки не трогай.
Диаграммы из текста (в формате ASCII/text) не перерисовывай и не меняй, только если они не ломаются из‑за правок вокруг.
Повествование в описательных частях веди от первого лица — так, будто разработчик рассказывает про свой проект: «сделал», «настроил», «реализовал», «поднял». При этом в инструкциях (разделы вроде «Требования» и «Шаги запуска») используй нейтральные формулировки для условий и повелительное наклонение для действий — чтобы было понятно, что это руководство для другого человека.
В итоге должен получиться текст, который можно сразу вставить в README.md и он будет выглядеть как нормальная документация от человека.

Ответ пришли БЛОКОМ КОДА для вставки в README.MD как есть. Я хочу просто его скопировать как блок кода.

Ниже представлен текст для редактирования:

---
````

## 📝 Особенности и контекст использования

- **Назначение:** Устранение «нейросетевого» и канцеляритного оттенка в `README.md` для IT-проектов.
- **Формат ответа ИИ:** Готовый блок кода Markdown, удобный для мгновенной вставки в файл через Copy & Paste.
- **Ограничения:** Полная сохранность технических параметров (версий, путей, флагов), ссылок, таблиц, разметки и текстовых диаграмм.
