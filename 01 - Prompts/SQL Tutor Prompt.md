## Схема базы данных (Pizzeria Domain)

1. **`pizzeria`** (справочник пиццерий)
   - `id` — первичный ключ
   - `name` — название пиццерии
   - `rating` — средний рейтинг (от 0 до 5)

2. **`person`** (справочник клиентов)
   - `id` — первичный ключ
   - `name` — имя
   - `age` — возраст
   - `gender` — пол
   - `address` — адрес

3. **`menu`** (справочник доступных пицц и цен)
   - `id` — первичный ключ
   - `pizzeria_id` — внешний ключ на `pizzeria`
   - `pizza_name` — название пиццы
   - `price` — цена

4. **`person_visits`** (журнал посещений)
   - `id` — первичный ключ
   - `person_id` — внешний ключ на `person`
   - `pizzeria_id` — внешний ключ на `pizzeria`
   - `visit_date` — дата посещения (например, 2022-01-01)

5. **`person_order`** (журнал заказов)
   - `id` — первичный ключ
   - `person_id` — внешний ключ на `person`
   - `menu_id` — внешний ключ на `menu`
   - `order_date` — дата заказа (например, 2022-01-01)
