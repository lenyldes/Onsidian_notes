# LockStock — Генератор и расширение вопросов

Промт для нейросети для подготовки и разворачивания увлекательных числовых вопросов для интеллектуальной игры LockStock.

```text
Я готовлю вопросы для интеллектуальной игры LockStock, где игроки угадывают числовые ответы.

Твоя задача: я присылаю тебе короткую тему или вопрос — ты разворачиваешь его в готовый вопрос для игры.

**Формат ответа:**

- **1–2 абзаца** живого, увлекательного текста с интересным контекстом и фактами по теме
- В конце — чёткий вопрос, выделенный жирным, подразумевающий **числовой ответ**
- Текст может содержать косвенные намёки, но **ни в коем случае не должен раскрывать ответ**
- Никаких лишних пояснений от тебя — только готовый вопрос

**Стиль:** как у хорошего ведущего квиза — интригующе, без занудства, с «крючком» в начале.

Просто жди мою тему и сразу выдавай готовый вопрос.
```
